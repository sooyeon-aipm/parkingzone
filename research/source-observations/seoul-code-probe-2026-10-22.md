실제 DB 생성·정기 수집·프로토타입 실데이터 연결·실제 UT는 미실행이다.

## 요청과 관찰 시각

`POST https://parking.seoul.go.kr/search/parking/list.do`

폼 항목: `Gu=성동구`, `Dong=성수동1가` 또는 `성수동2가`, `Keyword=빈 문자열`, `index=1`, `Type=63`, `Rule=0`.
최초 강변 검색의 `Keyword=강변` 응답까지 포함하여 주차장 조회 요청은 총 3회였다.

- 최초 강변 응답 수신: 2026-10-22T14:45:32.040645+00:00 (23:45:32 KST).
- 성수동1가 응답 수신: 2026-10-22T14:45:54.581427+00:00 (23:45:54 KST), 49행.
- 성수동2가 응답 수신: 2026-10-22T14:45:54.741640+00:00 (23:45:54 KST), 60행.
- 시각은 코드가 응답 수신 시 기록한 UTC를 KST로 환산했다. 원천 상태 시각은 별도 필드다.
- 두 지역 응답 모두 `result_state=0000`. 주소 기준 필터링 전 행 수이며 109개를 모두 대상 시설로 확정한 것이 아니다.

## 해석·한계

- 13개 정상 후보는 KST 가정과 응답 수신 시각 기준으로 기존 20분 임시 기준 안에 있었다.
- `cur_parking_time`을 실제 응답에서 찾았다. 앞선 화면 관찰에서 원천 시각을 못 찾았다는 기록은 그대로 유효하되, ‘원천에는 시각이 없다’로 일반화하지 않는다.
- `sync_time`은 시설정보 수정일 계열 값으로 상태 시각에 사용하지 않는다.
- 원천 상태 0/2/3과 미정 코드는 정상 수치 생성에 사용하지 않는다. 1회 조회 성공은 지속 수집·출처 최신성·입차 가능 보장이 아니다.
- 이 JSON은 일회 조사 증거다. 운영 수집의 성공 원본 상시 저장 정책을 새로 만든 것이 아니다. 정기 수집 시에는 합의대로 오류 확인에 필요한 최소 원본만 7일 보관한다.
- 공식 웹사이트의 이용 안내·반복 접근 조건과 시간대 의미는 반복 수집 전 확인 항목으로 남긴다. 이번 공개 응답 조회 성공이 재배포·공식 API 계약을 의미하지 않는다.

이번 기록은 최초 요청 뒤 저장한 지역 원본을 `--input`으로 다시 해석하여 만들었고,
재해석 과정에서 원천을 추가 조회하지 않았다.

별도 합성 입력으로 정상 뺄셈, 상태 0/2 차단, 범위 오류, 소수, 시각 없음, 미래 시각,
미정 코드, 주소의 별표·공백을 총 9개 검사했다. 파서 자체 점검이며 실DB·운영·독립 검증은 아니다.
