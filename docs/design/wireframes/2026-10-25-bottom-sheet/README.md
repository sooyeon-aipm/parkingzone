# 원본 바텀시트 구성 전환 · 수정 스케치

2026-10-25. 설계 스케치와 원본 관찰 기록. 후속 승인에 따라 로컬 프로토타입에 구현했다. 배포는 아직 반영하지 않았다.

## 사용자 수정

초기 높이는 약60%가 아니라 첫 ‘휴일3시간권(자주식)’ 카드의 6,000원 아래까지만 보이는 콘텐츠 기준으로 맞춘다. HTML은 첫 금액의 실제 위치를 측정해 높이를 계산하며 이용가능 시간·다음 상품은 초기 화면 아래로 둔다.

## 원본 직접 관찰

- 손잡이를 직접 위로 올려 완전 펼침을 확인했다. 이는 내부 스크롤이 아닌 시트 크기 변경 제스처다.
- 접힘: 검색박스/지도 유지,제휴 원형표시/좌측 시설명/카드결제/우측 내비.
- 펼침: 검색/지도 가림,중앙 시설명,‘제휴 | 154면’,전달·수정요청·즐겨찾기·내비4버튼,안내 배너/상품4개.
- 추가 스크롤: 시설명·면수는 위에 남고 기능4버튼/배너는 올라간다. 상품 뒤 이용권 모두보기/주소/시간요금이 이어지고 닫기X는 우측 아래에 남는다.
- 상품4개와 가격·이용시간은 원본에서 확인한 정보이며 실제 구매·공유·수정요청·내비는 실행하지 않았다.

## 추가 정보의 스케치 배치

혼잡도는 이름옆,갱신시각은 이름아래,현재상태박스는②본문에 두고③의 고정 여부는 비교안이다. 상태박스는 스크롤되지만 혼잡도/이름/시각/면수는 헤더에 유지하는 제안이다. 수집시각은 표시하지 않는다. 여유/갱신14:30/잔여100면은 배치용 예시이며 실시간관측값이 아니다.

## 마지막 확인 사항

검색은 사용자1안으로 확정했다(선택 직후 유지/완전 펼침에서 숨김). 아직 확인할 것은③의 상태박스가 고정되는지 본문과 함께 사라지는지다. 위 비교는 확인용 스케치이며 구현 선택을 대신 확정하지 않는다.

슬라이더는 높이와 구성 변화를 설명하는 스케치용 보간이다. 원본의 전환 임계점·속도·프레임을 측정했다고 해석하지 않는다. 고정된 초기/펼침/스크롤 상태와 캡처가 관찰 근거다.

`index.html` 또는 `http://127.0.0.1:8768/`에서 확인한다. 필요 시 프로젝트 루트에서 `python3 -m http.server 8768 --bind 127.0.0.1 --directory docs/design/wireframes/2026-10-25-bottom-sheet`를 실행한다.

## 후속 확정·아이콘 이동

- 검색: 사용자1안확정. 선택직후유지/완전펼침원본처럼숨김. 이 항목은 다시 질문하지 않는다.
- ②·③의 ‘제휴 | 154면’ 줄 제거. 원형 제휴 아이콘을 ‘주차장 현재 상태’ 제목 왼쪽으로 이동한다. 이번 시설은 제휴이며 다른 유형의 민영 아이콘을 임의로 만들지 않는다. ①은 기존대로 둔다. 전체면수는 상태박스의 분모에만 유지된다.
- 이전③은 상태박스가 스크롤되어 사라진 상태였다. 이번에③에도 아이콘을 보여달라는 요청은 상태박스 고정 여부와 맞물린다. 이를 임의확정하지 않고,③에고정하는임시안/이전처럼본문과함께사라지는안을선택기로비교한다. 최종확인사항은③의상태박스고정여부하나다.

## 최종 승인 및 로컬 구현 검증

사용자 마지막 1안 승인: ③에서도 현재 상태 박스 전체를 고정한다. 앞의 비교안·확인 대기 설명은 이 결정으로 대체한다.

- 초기: 검색 유지, 첫 상품 가격 아래 약 4px까지 노출. 실제 브라우저 측정 4.7px, 이용시간은 화면 밖.
- 펼침: 검색 숨김, 이름 중앙, 제휴·면수 메타 줄 제거, 유형 아이콘을 상태 제목 왼쪽에 배치.
