# 모두의주차장 개선 프로토타입

2026-10-24 현재 작업트리 실행 안내. 기존 서비스 구조에 혼잡도·원천 갱신 시각을 더하는 개선 프로젝트다. 실제 결제·예약·발급·주차장 등록·계약을 하지 않는다. Git 반영과 Vercel 배포 결과는 별도로 확인한다.

## 실행

프로젝트 루트에서 `python3 scripts/serve_prototype.py` 실행 후 http://127.0.0.1:8765 를 연다. 같은 서버가 이미 있으면 브라우저만 연다. 종료는 실행 터미널의 Ctrl+C. 정적 서버나 HTML 직접 열기로는 DB 조회 경로가 작동하지 않는다.

기본 주소가 실제 DB를 조회한다. 과거 data/demo/participant/case 쿼리로 더미·비교 화면을 고르지 않는다. 네이버 Dynamic Map은 기존 공개 Client ID와 콘솔 허용 도메인을 사용한다. 새 주소의 지도 인증은 해당 주소에서도 확인해야 한다. Client Secret·서비스 역할 키를 프론트에 넣지 않는다.

## 현재 구현

- 기존 15시설의 실제 현황과 관리 주소를 연결한다. 원천 미제공·조회 실패·오래된 기록을 정상 현재 상태로 만들지 않는다. 원천 갱신 시각과 수집 시각은 별개다.
- 자동 조회는 보이는 탭에서만 예약한다. 성공/실패 후60초 간격, 진행 중 요청 공유, 짧은 탭 복귀 생략, 실패 후 마지막 기록 유지/재시도를 적용한다. 개발용 자동 조회 토스트는 제거했다.
- 네이버 지도·주소 일치 좌표·목적지 기준 직선거리와 정렬을 사용한다. 차량 진입구나 실제 이동거리를 보장하지 않는다. 주차권OFF도 시설을 숨기지 않고 확인된 현장시간요금/P로 전환한다. 공유OFF는 확인된 공유면에만 적용한다.
- 목록/상세 시트의 포인터 드래그·펼침/중간/닫힘·목록 복귀, 내부스크롤과 정보 갱신 시 상태 보존을 구현했다. 실제 아이폰 터치 확인과 구분한다.
- 검색조건의 적용/취소/초기화, 확인된 제휴/공영/카드 조건을 연결했다. 미확인 특성은 조건에 맞는다고 가정하지 않는다. 현재 15시설에 확인된 무료/충전소 상세정보가 없으므로 해당 선택 화면은 빈 상태다.
- 즐겨찾기는 이 브라우저에서만 저장한다. 내 이용권/이용내역은 발급 없음 상태다. 테스트 선택 기록을 실제 이용권으로 바꾸지 않는다. 월주차·세차도 확인 상품이 없으면 빈 결과를 표시한다.
- 내 공유 개인 소유·시간제의 선택/조건/입력/사진 선택/로컬 검토를 연결했다. 입력·사진은 전송/영구 저장하지 않는다. 주소는 현재 텍스트 직접 입력이며 원본 주소검색·지도선택 전체 연결은 아니다. 거주자 우선/월주차는 관찰한 동의·외부신청 안내까지만 구현했고 이후 범위는 확인 대기다.

## 요금·날짜

오늘2026-10-24 확인 상품은5시설16개다. 상품별 출처·확인일·적용 날짜는 `data/facilities.json`에 기록한다. 공식 대조 없는 미래 날짜와 반복 요일로 확장하지 않는다. 다른 날짜에는 빈 결과가 나올 수 있다.

현장 요금은14/15곳 입력했다. 모두의주차장 미대조 값은 서울시 출처를 표시한다. 메가박스 시간요금·팩토리얼 추가단위·홍성 운영시간의 출처 충돌은 보류한다. 현장 요금으로 가짜 앱 상품을 만들지 않는다. 자세한 근거는 [요금 검토표](../docs/review/FEE_COMPARISON_2026-10-24.md)와 [공식 관찰 기록](../research/source-observations/modu-fee-review-2026-10-24.md).

한국 날짜·다음 달 선택·자정 경계에서 과거일 재검사를 지원한다. 조건에서 빠진 상품을 다른 상품으로 자동 대체하지 않는다. 2일 이상에는 확인된 연박권 유형만 표시하며 현재 카탈로그에는 없다.

## 검증·남은 일

`node --test prototype/*.test.mjs`로 로직 검사를 실행한다. 2026-10-24 최신39개 통과. 이는 전체 기존 앱 재현·실기기·배포·실제 UT 완료를 의미하지 않는다.

- AI 입력/결과는 미완료. 미러링 마이크 사용 제한, 별도 웹사이트의 현재위치 요청, 직접 공개 웹의 로그인 실패를 확인했다. 실제 음성 인식 성공이나 AI 응답을 가장하지 않는다.
- 실제 아이폰 Safari의 주소창/키보드/시트 터치/안전영역, 최신 미리보기와 운영 주소의 통합 확인이 남아 있다.
- 현재 Vercel Chrome 계정에서 기존 parkingzone 프로젝트 접근을 확인하지 못했다. 다른 계정에 임의로 배포하지 않는다. [미리보기 준비](../docs/review/PREVIEW_PREPARATION.md) 참고.
- 내 공유의 거주자/월주차 범위 질문과 실제 원본 주소 검색 재현 확인이 남아 있다. 전체 재현 완료로 표시하지 않는다.

[전체 개선 플랜](../docs/design/DEPLOYED_PROTOTYPE_IMPROVEMENT_PLAN.md), [진행·검증 기록](../docs/records/DEPLOYED_IMPROVEMENT_PROGRESS.md)을 따른다. 과거 더미 JSON·비교 자료·live-data.js는 현재 앱의 실행 데이터 경로가 아니다.
