## 확인 범위와 프로토타입 활용

- 참고 순번은 문서에서 가리키기 위한 번호다. 우리 DB의 실제 기본키나 제공처 시설 ID가 아니다.
- 실시간 조회 가능 여부는 사용자 확인에 따른 설명이며 시설별 현재 응답·연계 상태를 AI가 독립 검증한 것은 아니다.
- 시설별 전체면수·가능면수·원천 갱신 시각·원천 시설 ID는 이 목록에 없다. 수치를 임의로 채워 실제 수집값으로 보고하지 않는다.
- source_parking_id는 실제 제공처 ID를 확인하기 전까지 NULL이다. 원천 갱신 시각도 실제 수집 여부와 프로토타입의 가상 시각을 구분한다.
- 모두의주차장 판매 시설과의 동일성·주차권 판매 연결·현장 입차 가능 여부는 별도 미확인이다.
- 실제 시설 이름·주소에 프로토타입 가상 현황을 연결할 경우 ‘시설명·주소: 사용자 제공 / 주차 현황: 테스트용 가상값’으로 구분하여 표시한다.
- 사용자 B1 선택으로 이 15개 시설 전체를 기본정보로 사용하고 테스트용 가상 현황·상태·예외 시나리오를 연결하기로 합의했다. 이후 prototype/data/parking.json과 화면에 15개를 연결했다. 이름·주소 이외 값은 가상이며 실제 수집 결과가 아니다.
