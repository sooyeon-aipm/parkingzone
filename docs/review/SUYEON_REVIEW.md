# 수연 검토 요청 — 10월23일 목표 과제

기준일: 2026-10-22. **기본 산출물 준비·검토 요청 가능 / 수연 최종 승인 대기**.

## 현재 상태

- 사용자 보고: 유미·종현이 기존 결과물을 확인했고 추가 보완 없다고 전달했다. 수연은 아직 검토하지 않았다.
- 이후 승인된 참여자용 보기 추가: 진행자 메뉴 숨김, 3상황 링크, 조건 유지 재시작, 종료 화면의 내부 상황 이름 숨김을 AI가 구현·Chrome 검사했다. 이 추가 변경까지 유미·종현이 재검토했다고 추정하지 않는다. 수연 검토 범위에 포함한다.
- 23일 14시 목표인 DB 기본 설계·컬럼·구현 방식 설명과 최소 3개 더미 동작 프로토타입의 기본 산출물은 준비되어 있다. 프로토타입은 15개 더미 시설을 사용한다.
- 실제 DB 저장/자동 수집 실행은 보류, 실제 사용자 UT 실시·분석은 미실행이다. 과제 준비와 최종 승인/운영 구현/실제 사용자 성과를 구분한다.

## 검토 순서

1. [DB 설계·컬럼·연결 규칙](../design/DB_DESIGN.md): 기본정보 5개, 상태 8개, 수집 기록 9개 컬럼과 관계. 뒤쪽 추가 컬럼까지 함께 읽는다.
2. [최종 검토 요약](FINAL_REVIEW.md): 수집→검증→상태/시도 기록→표시 흐름과 정상/예외의 기대 동작.
3. 아래 참여자용 화면에서 목록→상세→펼침→복귀→선택 종료 확인.
4. [UT 설계](../ut/UT_DESIGN.md): 개선안 정보 이해도를 먼저 확인할 3상황·3요소 관찰. 실제 UT 결과가 아니다.

| 검토 화면 | 현재 컴퓨터에서 열기 | 기대 표시 |
| --- | --- | --- |
| 진행자용 | http://127.0.0.1:8765/?layout=1 | 비교 모드·상태 선택·참여자용 링크 |
| 참여자 1 | http://127.0.0.1:8765/?participant=1&case=1 | 정상: 여유, 갱신 11:55 |
| 참여자 2 | http://127.0.0.1:8765/?participant=1&case=2 | 지연: 확인 필요, 갱신 11:30, 마지막 기록 |
| 참여자 3 | http://127.0.0.1:8765/?participant=1&case=3 | 시각 미확인: 확인 필요·미확인 |

기대 표시는 첫 시설 강변의 가상 예시이며 테스트 판단 시각은 고정 12:00 KST다. 링크의 case 번호와 상황 설명은 진행자용 자료다. 참여자 화면에는 진행자 메뉴와 종료 화면의 내부 상황 이름을 표시하지 않는다.

링크는 이 컴퓨터의 로컬 서버 주소이며 공개 배포 주소가 아니다. 지금은 이 컴퓨터에서 열거나 화면 공유로 검토한다. 다른 컴퓨터에서는 프로젝트 파일을 받아 [실행 안내](../../prototype/README.md)에 따라 별도로 실행해야 한다. 최신 공유 여부와 이력은 저장소 main 및 개발기록서를 확인한다.

## 구현·검사 근거

- 새 참여자 보기의 3상황별 목록/상세 표시를 Chrome에서 확인했다.
- 지연 조건에서 종료→다시 테스트하기 후 지연 조건 유지, 미확인 링크 새로고침 후 미확인 조건 유지를 확인했다.
- 구매 종료 검사만 localhost의 별도 저장 영역에서 수행했고 공유 중인 127.0.0.1의 기록에 AI 시험 구매를 추가하지 않았다.
- 참여자 종료 화면에는 기존안/개선안·진행자 상황 이름이 보이지 않는다.
- 360×800 브라우저 화면에서 진행자 메뉴 숨김과 가로 넘침 없음(페이지 360px)을 확인했다. 실제 스마트폰 기기 검사는 아니다.
- JS 문법·문서 변경의 diff 검사를 통과했다. 실제 사용자 UT, 실제 DB/수집 운영의 검증 결과가 아니다.

## 수연에게 설명할 한계

- 실제 주차 현황·판매 상품·실제 좌표/거리/입차 가능성을 제공하는 서비스가 아니라 고정 더미데이터의 연구용 프로토타입이다.
- 실제 원천 시설 식별자·갱신 시각 확보 가능성, 구체 DB 제품/SQL 및 수집 운영 조건은 미정/보류를 유지한다.
- 지도는 성수동 일반 지도 캡처, 표식은 가상 위치다. 시설 사진·시설별 실제 이용/환불 조건은 미확인 영역으로 표시한다.
- 사용자가 취소한 상세 여백 수정은 적용하지 않았다. UI 일부 선택이 전체 최종 승인이나 팀 학습의 정량 점수는 아니다.
