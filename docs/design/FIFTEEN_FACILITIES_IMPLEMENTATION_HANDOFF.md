## 데이터 출처·보존

서울시 시설 UUID/이름/지번은 유지하며 앱 이름·도로명은 별도 메타에 저장했다. 현황은 기존 Supabase DB 조회를 유지한다. 앱에서 읽은 면수 메타와 실시간 상태 박스의 제공처 면수는 출처가 다르므로 따로 유지한다.

`observed_products`는 아이폰에서 직접 본 2026-10-25 화면의 날짜별 관찰값이다. 기존 `products`를 덮어쓰지 않는다. 이미 알려진 상품 ID는 재사용하고, 새로 본 상품은 `observed-우리시설UUID-순번` 형태의 **로컬 관찰 ID**를 사용한다. 제공처 상품 ID를 추측하지 않았다. 새 항목의 출처는 원본 캡처 경로다. 조건 상세가 확인되지 않은 상품에는 조건 미확인을 표시한다. 과거 확인 조건이 있는 상품은 해당 근거를 보존한다.

새 관찰값은 10/25에만 판매 상태를 적용한다. 다음 날짜에 자동 재사용하지 않는다. 미래 날짜에서 정보가 사라지면 자동 수집 완료가 아니라 날짜별 새 검증이 필요한 상태다. 소스 페이지의 ‘미리보기4개’가 전체 상품을 뜻하지 않는다.

무신사E1·누디트 연결 시설의 원본 요금과 기존 서울시 요금 차이는 `reference_history`에 기존값을 보존하고 오늘 앱 원본의 현장 기본·추가요금으로 화면 메타를 반영했다. 과거 서울시 일최대요금을 오늘 앱에서 확인한 값으로 포장하지 않도록 두 시설의 미대조 일최대값은 현 표시에서 제외했다.
