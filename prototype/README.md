# 모두의주차장 개선 프로토타입

현재 구현 기준: 2026-10-23. 기존 앱 캡처의 검색·목록·상세 구조를 유지하며 혼잡도와 원천 갱신 시각을 추가한다. 로그인·실제 결제·예약은 범위에 포함하지 않는다.

## 실행

프로젝트 루트에서 `python3 scripts/serve_prototype.py`를 실행하고 http://127.0.0.1:8765 를 연다. 이미 같은 서버가 실행 중이면 브라우저만 연다. 종료는 서버 터미널에서 Ctrl+C다. 정적 서버나 HTML 직접 열기로는 DB 조회 경로가 작동하지 않는다.

기본 주소에서 실제 DB를 조회한다. 기존안·개선안 전환, 시나리오 전환, 더미데이터 선택 UI는 제거했다. 과거의 `?data=live` 선택은 더 이상 필요 없다.

## 실제 연결 범위

- Supabase에 사용자 제공 15개 시설을 등록했다. 2026-10-23 01:25 KST 예약 실행에서 15곳의 결과를 확인했다. 정상 저장 10곳, 원천 미제공 5곳이었다. 이 결과는 그 시점의 관찰이며 고정 상태가 아니다.
- DB 수집은 5분 주기다. 열린 화면은 1분마다 DB를 다시 조회하고, 탭으로 돌아올 때도 조회한다. 원천 갱신 시각과 수집 시각은 별개다.
- 네이버 Dynamic Map 실제 지도를 연결했다. 공개 Client ID와 localhost/127.0.0.1 도메인 제한을 사용하며 Client Secret은 프론트에 넣지 않는다.
- Geocoding 결과의 지번이 관리 주소와 일치하는 경우만 표식을 표시한다. 15곳 일치를 확인했다. 주소 좌표이며 차량 진입구를 확인한 결과는 아니다.
- 확대·축소·성수동 초기 위치 이동, 주차장 표식에서 상세 열기, 단일 시설 검색 시 지도 이동을 연결했다.
- 목록·상세에서 실제 면수·원천 시각·수집 결과를 표시한다. 원천 미제공·실패·오래된 기록은 정상 현재 상태로 표시하지 않는다.

## 남은 구현과 확인

- 확인된 공식 상품은 4개 시설의 6개다. 팩토리얼 성수 1시간권 3,900원·3시간권 15,000원, 무신사S1 1시간권 3,000원, 메가박스스퀘어 3시간권 5,700원·당일권 20,300원, 서울숲IT밸리 야간권 4,000원이다. IT밸리는 확인 당시 11:00 판매예정으로 표시된다. 오늘 주차권 목록은 확인된 상품만 표시하며 지도에는 15곳을 유지한다. 검증된 출처와 확인일이 없는 상품은 표시하지 않는다. 아직 구매 흐름 전체를 완료했다고 볼 수 없다.
- 검색에서 선택한 목적지부터 각 주차장 주소 좌표까지 직선거리와 거리순 정렬을 연결했다. 목적지를 선택하기 전이나 좌표 미확인 때는 거리를 만들지 않는다.
- 날짜는 한국 시간의 오늘을 기준으로 표시한다. 상품별 날짜·이용시간 판매 조건 필터와 다음 달 선택은 미연결이다.
- 서울숲메가박스스퀘어와 서울숲IT밸리는 서울시 시설·위치를 유지하며 공식 상품을 연결했다. [실제 자료 검토](../research/source-observations/modu-product-review-2026-10-23.md)를 확인한다.
- 공유면·월주차·세차·AI·즐겨찾기 등은 화면 참고 버튼이며 해당 서비스 기능은 미구현이다.
- 실제 사용자 UT, 수연의 최종 검토, 공개 배포는 수행 사실로 주장하지 않는다.

## 파일

`app.js`는 화면, `model.js`는 상태 판정, `catalog.js`는 시설과 실제 DB 관측 연결, `parking-map.js`는 네이버 지도 연결을 담당한다. `data/facilities.json`에는 관리 시설 원문과 확인된 상품 메타데이터만 둔다.

과거 더미 JSON·비교 자료·`live-data.js`는 기존 기록으로 남아 있으나 현재 앱의 데이터 경로로 사용하지 않는다. 이 문서의 현재 상태와 과거 기록을 구분한다.
