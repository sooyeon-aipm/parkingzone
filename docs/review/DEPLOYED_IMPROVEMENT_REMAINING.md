## 결정된 사항

- 충돌값 보류, 나머지 서울시 단독 요금은 출처·미대조 문구와 함께 표시: 사용자 승인.
- 상품은 확인한 날짜에만 적용: 사용자 승인.
- 원본은 미러링으로 직접 조사: 재연결 성공. 실제 동의·신청은 실행하지 않음.
- Vercel은 팀원 계정에 있으며, 기존 GitHub 커밋/푸시 경로로 재배포 확인: 최신 사용자 안내.

## 남은 질문

1. 내 공유 거주자/월주차: 안내·외부 절차 경계만 재현 / 추가 원본 확인 뒤 확장 / 보류 / 기타.
2. AI: 원본 입력·결과 확보 뒤 재현 / 15시설 텍스트 검색 대체 / 첫 화면만 / 기타.

근거: 실행 기록, 요금 대조표, 원본 관찰 자료. 로컬 검사 통과를 전체 구현·배포·UT 완료로 해석하지 않는다.
