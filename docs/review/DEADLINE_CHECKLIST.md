## 마감 완료를 확정하기 전에 남은 확인

- 목표 범위의 DB 설계·컬럼·구현 흐름을 한 번에 검토하고 미정/보류 항목을 설명할 수 있는지 팀이 확인한다. 실제 자동 수집이나 DB 구축을 새로 요구하는 것이 아니다.
- UT에 사용할 화면·환경에서 핵심 흐름과 정상/지연/미확인 표시를 팀이 최종 확인한다. 현재의 모든 앱 참고 버튼·비핵심 기능을 실제 서비스 수준으로 완성하라는 뜻이 아니다.
- 참여자가 수행할 간단한 과업과 진행자의 시나리오 전환/관찰 방법을 정리해 ‘UT가 가능하다’는 준비 상태를 확인한다. 실제 UT 실시까지 이번 마감 필수로 확대하지 않는다.

판정: 23일 목표의 기본 산출물 작성·구현은 준비되어 있다. 사용자 보고로 유미·종현의 기존 결과물 확인을 기록했다. 승인된 참여자용 보기도 추가·검사했으므로 수연 검토를 요청할 수 있는 상태다. 수연의 최종 승인과 실제 사용자 UT/운영 구현 완료는 별도다. [수연 검토 자료](SUYEON_REVIEW.md)를 따른다.
