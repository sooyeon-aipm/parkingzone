# 모두의주차장 내 공유 원본 관찰

2026-10-24, 아이폰 미러링에서 직접 조작. 실제 등록·신청·개인정보 입력·원본 개인정보 동의는 하지 않았다.

- 지도 하단 내 공유 → 내 공유주차장. 빈 주차공간 수익 안내, 무단 주차 예방 설명, 주차장 등록하기.
- 유형: 거주자 우선(주거지): 구청 배정 구획 / 개인 소유: 집·가게·빌라 등의 주차 공간. 선택 전 다음 비활성.
- 거주자 우선 → 개인정보 수집·이용 안내. 목적은 배정 정보 유효성 확인, 항목은 차량번호·생년월일·연락처, 보유는 공유 기간 동안/만료 후 폐기. 대리등록은 당사자 동의를 먼저 받으라는 안내. 동의 체크와 배정정보등록 버튼. 원본에서는 동의하지 않고 뒤로 닫았다. 이후 화면 미관찰.
- 개인 소유 → 운영방식: 시간제(30분 단위 요금), 월주차(비워두는 시간 규칙적인 경우).
- 월주차 → 신청서 작성을 위해 웹페이지로 이동한다는 닫기/계속하기 안내. 비구속 안내의 계속하기로 biz.modu.kr 웹뷰를 열었다. 주차장밸류업, STEP1 원하는 서비스 선택, 모두의주차장 파트너/쏘카 파트너 신청 카드와 메일 문의 안내를 확인. 개인정보 입력·신청은 하지 않음. 웹뷰 클릭 입력이 즉시 전달되지 않았고 닫기는150ms누름으로 동작했다. 이후 신청 분기 미관찰.
- 시간제 → 외부인 주차 가능 여부와 지정주차면 여부 선택. 미선택이면 다음 비활성. 외부인 아니오·지정주차면 예에서 다음을 누르면 ‘공유 등록 불가합니다 / 공유 조건을 모두 만족하는 경우에만 등록 가능합니다’ 안내.
- 두 조건 예 → 주차환경 전경사진 및 토지·건물 관계증빙 사진 준비 안내 → 필수정보 입력.
- 필수정보 입력: 이름,주소검색/지도,면수,30분요금,선택 설명,필수 주차환경사진/토지·건물 관계증빙 사진. 원본 입력과 등록은 하지 않음.

구현 경계: 개인 소유·시간제 입력은 로컬 검토까지 시연. 원본 주소검색·지도 선택 전체를 연결한 것은 아니며 주소 텍스트만 로컬 입력한다. 거주자/월주차는 동의·외부연결 안내까지만 우선 반영했으며 이후 깊이는 사용자 확인 대상이다. 계약·동의를 대신 수행하거나 미관찰 화면을 원본으로 가장하지 않는다.
