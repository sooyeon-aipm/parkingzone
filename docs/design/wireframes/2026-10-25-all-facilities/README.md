# 15곳 원본 대조 및 와이어프레임

2026-10-25. 사용자가 직접 아이폰에서 검색하고 AI가 미러링으로 펼침·스크롤·닫기 및 캡처를 수행했다. 5번 팩토리얼은 같은 날짜 앞선 관찰을 재사용한다. 연결 판단은 사용자 제공 목록을 따른다. 실제 개명 여부·미래 판매·실제 구매·현장 운영을 검증한 것이 아니다.

- [클릭 가능한 스케치](http://127.0.0.1:8769/): 15곳 선택, 초기/펼침/스크롤 3상태, 지도 선택/해제 비교, 원본 캡처 링크.
- `observations.json`: 원본 화면에서 읽은 표시값. 런타임 데이터와 별개. 날짜는 관찰 맥락이며 미래 날짜 판매 근거가 아니다.
- `evidence/`: 원본 캡처와 스케치 캡처. 지도와 타입 아이콘은 스케치용 CSS이며 새 실제 지도 기능이 아니다.
- 상세 기록: `../../FACILITY_MAPPING_REVIEW.md`
- 주차권 수집 조사: `../../MODU_PASS_COLLECTION_FEASIBILITY.md`

## 반영한 결정

1. 초기에는 검색 유지, 완전 펼침에는 검색 가림.
2. 혼잡도는 이름 옆, 갱신 시각은 이름 아래. 수집 시각 표시 없음.
3. 펼침·스크롤에서는 기존 ‘유형 | 면수’ 줄 제거. 제휴/공영/민영 아이콘을 상태 제목 왼쪽으로 이동.
4. 제목·갱신 시각·상태 박스 전체 고정. 기능4개·안내 배너·상품·주소는 본문 흐름에 배치.
5. 제휴는 해당 시설의 상품·배너·판매 불가 상태 사용. 공영·민영 결제 미지원 시설에 가짜 상품 카드를 만들지 않음.
6. 지도는 제휴 원형 라벨+관찰 가격, 비제휴 가격 말풍선. 선택 시 진한 파랑, 선택 해제 시 원래 밝은 파랑/흰색으로 복원하는 사용자 요구를 스케치로 표현. 원본 X 닫기 후 진한 색이 남는 경우도 있어 원본의 모든 경로가 동일하다고 주장하지 않음.

## 확인할 사항

- 공영·민영 초기 높이는 시간요금·운영시간까지만 보여주는 제안이며 아직 승인 전.
- 지도 10번·14번은 해당 말풍선 가격의 연결 미확인. ‘금액 확인 대기’는 설계 주석이며 최종 앱 문구로 승인한 것이 아님.
- 1번·12번 사진 표지 요금과 앱 본문이 충돌. 스케치는 앱 본문 관찰값이며 현행 요금 확정은 보류.
- 지도 가격은 첫 상품 가격과 다를 수 있음. 서로 임의 대체하지 않음.
- 혼잡도 ‘여유’, 갱신 --:--, 잔여 —면은 명시된 배치 예시이며 실제 DB 현황 아님. 원본 전체면수는 실제 화면 관찰값이며 서울시 현황의 전체면수와 일치 여부는 다음 데이터 대조 대상.

## 검토한 범위

브라우저에서 15개 선택 항목, 공영·제휴 제한 안내·민영·전체 이용 불가 상태를 확인했다. 제휴 초기 가격 하단 여백 약 4.8px, 흰색 말풍선 선택 해제 복원 확인. 이 검토는 프로덕션 구현·배포·실제 UT를 의미하지 않는다. 프로토타입 코드·운영 DB는 이번 조사에서 변경하지 않았다.

실행: `python3 -m http.server 8769 --bind 127.0.0.1 --directory docs/design/wireframes/2026-10-25-all-facilities`

## 2026-10-25 사용자 결정 반영

- 공영·민영 초기 높이: 시간요금·운영시간까지 노출 확정.
- 지도 가격: 모든 시설을 현장 1시간 요금으로 통일. 관찰된 기존 지도 가격은 별도 기록으로 보존하고 최종 지도 가격의 기준으로 사용하지 않는다. 상품 최저가와도 구분한다.
- 요금 충돌은 시설공단 현행 요금 추가 대조 후 결정. 공식 공영 현황에서 강변(건물)/둘레길 47-5와 성수1가1동(건물)/성덕정1길 6 모두 5분 250원 확인. 공식 2026-09-23 공지에서 2026-10-01 00:00부터 기존 5분150원·1시간1,800원 → 5분250원·1시간3,000원 변경 확인. 따라서 두 시설의 스케치/후속 구현 기준은 1시간 3,000원으로 정리한다. 사진 표지의 촬영 시점은 알 수 없지만 현행 공식 요금보다 우선하지 않는다.
- 공식 근거: https://parking.happysd.or.kr/Public/PresentTab2 및 https://parking.happysd.or.kr/Guest/NoticeViewNew?seqNo=596&page=1
- 지도 시간당 요금은 무료시간/감면을 제외한 기본요율을 표시한다. 갤러리아포레의 10분2,000원은 시간당12,000원이며 초기 무료20분을 별도 안내한다. 첫60분 실제 결제액 견적과 구분한다.
- 무신사E1·누디트 연결 시설은 서울시 예전 데이터와 오늘 원본의 기본요금이 다르므로 원본의 현장요금 기준 설계값과 기존 서울시 값을 각각 보존한다. 수집 원본을 덮어쓰지 않는다.
- 현재 변경 범위는 설계/스케치뿐. 런타임·DB·배포 미반영.
