# 캡처 기반 동작 프로토타입 — 팀 학습용

> **최신 정정 — 진행률 재산정 중:** 기존 ‘구현 학습 60%/80%’는 철회했다. AI 구현·검사와 팀 학습·합의 완료를 구분한다. 사용자는 영역별 표시(A2)를 선택했다. 전체 50% 계산안은 사용하지 않는다. DB 기본 설계 합의만 기존 4/4 기준 100%이며 프로토타입 최종 검토·UT 준비는 분모/완료 근거 확정 전 산정 대기다. ‘다음 단계’는 먼저 필요한 질문을 제시한다는 뜻이다. [진행도 기준·근거·다음 질문](../docs/review/PROGRESS_REVIEW.md)을 먼저 읽는다. 취소된 상세 여백 수정은 적용하지 않는다.

기존 구현 학습 80% 표시는 철회했다. 아래는 AI가 작성·검사한 기능 기록이며 팀 학습 진행률이 아니다. 한 시설 연결에 이어 15개 시설·검색·정렬·선택 연동을 Chrome에서 확인했다. 예외 전환·비교·테스트 종료도 코드와 브라우저에서 연결했지만, 팀 검토와 원본 화면 재현 점검이 남아 전체 완료로 세지 않는다.

사용자의 최신 요청은 ‘새로운 서비스처럼 만든 예시’가 아니라 기존 모두의주차장 앱을 사용하는 듯한 화면·흐름 재현이다. 캡처의 검색 카드, 필터, 바텀시트 목록, 상품 상세 축약/펼침, 고정 구매 버튼을 기준으로 1차 수정했다. 앱 전체 또는 픽셀 단위 일치가 완료된 상태는 아니다.

## 실행

프로젝트 루트에서 실행한다. 이미 8765 서버가 실행 중이면 브라우저만 열면 된다.

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory prototype
```

http://127.0.0.1:8765 에서 확인한다. 종료는 서버 터미널 Ctrl+C. HTML 파일을 직접 열면 JSON을 읽지 못할 수 있다. 외부 API·로그인·결제·실제 DB·자동 수집과 연결하지 않는다.

## 데이터와 지도 한계

시설명·주소는 사용자 제공 15개 자료다. 상품·가격·거리·전체면수·가능면수·시각은 가상이다. 실제 시설 상태·판매 제휴·입차 가능 여부를 뜻하지 않는다.

`assets/seongsu-map-capture.png`는 Kakao맵의 성수동 일반 지도를 캡처한 배경이다. 실제 주차 현황·검색 표식을 가져오지 않았고, 우리 표식은 테스트용 가상 위치다. 출처는 화면에 표시한다. [캡처 기록](../research/source-observations/seongsu-map-2026-10-22.md)을 따른다. 이전 서울시청 원본 파일은 비교 출처 자료로 보존하며 현재 화면에서는 참조하지 않는다.

입구·내부 사진과 시설별 차량 제한·환불 조건은 확인 대기다. 캡처 속 아마노 주차장의 정보를 성수동 시설의 실제 정보로 옮기지 않았다.

## 팀원이 읽는 순서

| 파일 | 역할 | 함께 볼 내용 |
| --- | --- | --- |
| data/parking.json | 시설과 가상 상태·상품 | 동일 시설의 id와 parking_id가 일치하는가 |
| model.js | 상태 판단과 화면용 데이터 | 오래된 기록을 현재 배지로 보이지 않게 하는 이유 |
| index.html | 화면 뼈대 | 지도·목록·상세가 어떻게 나뉘는가 |
| styles.css | 캡처를 참고한 모양 | 크기·여백·색·바텀시트 위치 |
| app.js | 선택과 화면 이동 | selectedId로 같은 상품 상세를 찾고, 돌아왔을 때 선택을 유지하는 흐름 |

예를 들어 강변 상품을 누르면 `openDetail(id)`가 선택 ID를 기억한다. `renderDetail()`은 그 ID의 시설을 찾고 `buildView()`로 상태를 판단한다. HTML/CSS는 같은 화면을 유지하면서 기존안에서는 새 상태 영역만 생략한다.

추천 학습 분담은 유미: 캡처와 목록·상세의 간격/배치 비교, 종현: JSON의 ID 연결과 정상/예외 표시 확인이다. 실제 업무 배정으로 확정한 것이 아니다.

## 테스트 기록

구매하기 동작은 사용자 1안 선택으로 확정했다. localStorage의 `parkingzone-ut-selections-v1`에 선택 결과를 저장한다. 결제 정보·차량 번호·계정 정보는 받지 않는다. 기록은 해당 브라우저·출처에만 남고 다른 팀원의 브라우저와 공유되지 않는다.

최근 7일 기록만 읽고 시작·선택 저장 시 기한 초과 기록을 정리한다. 브라우저를 닫아 둔 동안 자동 삭제 작업이 돌아가는 것은 아니다. 실제 DB의 7일 보관/매시간 삭제 설계와 별개다. 기준 시각은 실제 `recorded_at`, 화면 현황은 고정 `data_as_of`로 구분한다. 저장 실패 시 성공 화면을 열지 않는다.

AI가 기능 점검에서 생성한 테스트 선택은 실제 사용자 UT 결과와 구분한다. 브라우저의 전체 저장 건수만으로 실제 사용자 UT 횟수를 판단하지 않는다.

## 확인한 것과 남은 것

확인: JS 문법, 15개 UUID 중복 없음·시설/상태/수집 연결, 5단계 분포와 4가지 예외 판단. 데스크톱 Chrome의 모바일 프레임에서 검색, 정렬, 상세 축약/펼침, 목록 복귀 시 스크롤/선택 유지, 상태 모드, 예외 전환, 구매 테스트 종료, 새로고침 후 기록 유지, 날짜·시간 선택을 확인했다.

남음: 캡처와 세부 시각 비교, 날짜와 상품 종류 조합의 판매 조건, 실제 모바일 기기·실사용자 UT. 픽셀 일치·앱 전체 기능·실제 DB/수집 구현을 완료했다고 주장하지 않는다.

## 2026-10-22 추가 결정 및 목록 배치 수정

- 사용자는 A1/B1을 선택했다. 성수동 지도 캡처 배경+가상 표식, 일반 주차권 검색→비교→상세→구매 전 흐름으로 재현 범위를 확정했다. 공유면은 이번 범위에서 제외한다. 성수동 배경 교체 자체는 아직 미수행이며 현재 서울시청 임시 배경을 실제 성수 지도라고 주장하지 않는다. 앞선 지도·공유면 질문 대기 문구는 이 결정으로 해소한다.
- 개선안 목록의 같은 행을 ‘혼잡도 배지 → 주차장 이름 → 갱신 시각 → 거리’로 변경했다. 긴 시설명은 한 줄 말줄임하고 원문은 title·상품 상세에 유지한다. 기존안은 새 상태/갱신 시각을 계속 숨긴다.
- 원천 갱신 시각 없음/최근 기록 없음의 짧은 표시 문구는 아직 제안 단계다. ‘시각 미확인’을 추천하며, 상세의 미확인 사유는 유지하는 방향이다. 사용자 선택 전에는 현재 문구를 임의로 교체하지 않는다.

## 이전 AI 작업 기록 — 당시 학습 60% 표시는 철회

- 성수동 일반 지도 캡처 배경으로 교체했다. 실제 주차 현황·검색 표식을 제거한 Kakao맵 캡처를 쓴다. 시설 표식 위치·거리·상품·상태는 여전히 가상이며 실제 시설 좌표로 검증한 것이 아니다. 출처·가상 위치 안내를 화면에 표시한다. 조사 기록은 [성수 지도 기록](../research/source-observations/seongsu-map-2026-10-22.md)을 따른다(프로토타입 README에서는 ../research/ 경로).

## 이전 상세 배치·AI 검사 기록 — 당시 학습 80% 표시는 철회

- 사용자 요청: 7번 상품 상세 화면의 혼잡도 배지를 주차장 이름 바로 왼쪽에 붙여 한 줄로, 갱신 시각은 그 아래 가운데 정렬한다. 축약/펼침의 공통 헤더에 적용했다. 상태 카드의 중복 배지·시각은 제거했다. 기존안에서는 새 정보가 숨겨진다. 목록의 확정 1안 배치는 유지한다.
- 유미·종현님이 같은 화면을 보며 진행 중이라고 사용자가 알려 주었으므로 같은 화면을 본다는 이유로 학습 질문·합의를 생략하지 않는다. 사용자의 최신 정정에 따라 ‘다음 단계’에는 필요한 질문을 먼저 제시한다. 팀원이 무엇을 실제로 검토·학습했는지는 추정하지 않는다.

## 최신 선택 — 영역별 진행도와 정보 이해도 UT 설계

사용자는 A2/B1/C1을 선택했다. 전체 진행률 대신 영역별로 표시하고, 다음 학습은 UT 설계이며 우선 검증 목적은 상태·갱신 시각·불확실성 이해다. 실제 사용자 UT는 미실행이다. [다음 학습 설명과 질문](../docs/ut/UT_DESIGN.md)을 따른다. 상황 범위·판정·진행 방식은 제안 단계이며 이번 작업에서 UI/데이터/수집 정책을 추가 변경하지 않았다.

## 참여자용 보기 — 승인·구현 완료

사용자가 1안을 선택했다. 진행자 화면의 ‘참여자용 보기’ 링크 또는 아래 주소를 사용한다.

- 정상: http://127.0.0.1:8765/?participant=1&case=1
- 갱신 지연: http://127.0.0.1:8765/?participant=1&case=2
- 원천 시각 미확인: http://127.0.0.1:8765/?participant=1&case=3

참여자 화면에서는 진행자 설명·모드 선택·시나리오 메뉴를 숨긴다. 종료 화면에도 내부 모드/상황 이름을 숨기며, 다시 테스트하기/새로고침 후 해당 링크의 조건을 유지한다. 진행자 화면은 기존 비교·초기화 동작을 유지한다. URL은 case 번호만 쓰며 상황 이름을 주소에 적지 않는다. 프로토타입의 가상 데이터 안내는 유지한다.

사용자는 유미·종현이 기존 결과물을 확인했다고 알렸다. 이후 참여자용 보기 추가는 AI가 Chrome에서 검사했으며 수연 검토는 대기다. 전체 검토 안내는 [수연 검토 자료](../docs/review/SUYEON_REVIEW.md)를 따른다. 로컬 주소는 다른 컴퓨터의 공유 URL이 아니며, 실제 스마트폰 기기 검사·실제 사용자 UT는 미실행이다.
